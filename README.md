# 维稳指挥系统 · Stability-Maintenance Command System

一款讽刺性策略游戏，设定于虚构国家「达尔坎斯坦」的卡拉城。
A satirical strategy game set in the fictional city of Kala, Darkanstan.

**在线游玩 / Play online:** 开启 GitHub Pages 后，访问本仓库的 Pages 链接即可。

- 三语支持：中文 / English / ئۇيغۇرچە（右上角切换）
- 单文件离线游戏，无需任何服务器或依赖
- 进度自动保存在浏览器本地（localStorage）

Trilingual (Chinese / English / Uyghur — switch in the top-right corner).
A single self-contained HTML file; no server or dependencies required.
Progress auto-saves to the browser's localStorage.

> 本游戏设定于虚构国家。任何将文化习俗标记为「威胁」的系统，本身就是最大的威胁。
