# 维稳指挥系统 · Stability-Maintenance Command System

一款讽刺性策略游戏，设定于虚构国家「达尔坎斯坦」的卡拉城。
A satirical strategy game set in the fictional city of Kala, Darkanstan.

**在线游玩 / Play online:** 仓库已包含 GitHub Pages 工作流（`.github/workflows/pages.yml`）。在仓库设置中将 Pages 来源设为 GitHub Actions 后，推送到 main 即自动部署。
The repo ships a GitHub Pages workflow; set Pages source to "GitHub Actions" in the repo settings and every push to main deploys.

- 四语支持：中文 / English / Português (pt-PT) / ئۇيغۇرچە（右上角切换；维吾尔语为从右到左排版）
- 单文件离线游戏，无需任何服务器或依赖
- 进度自动保存在浏览器本地（localStorage）

Four languages (Chinese / English / European Portuguese / Uyghur, right-to-left — switch in the top-right corner).
A single self-contained HTML file; no server or dependencies required.
Progress auto-saves to the browser's localStorage.

> 本游戏设定于虚构国家。任何将文化习俗标记为「威胁」的系统，本身就是最大的威胁。
